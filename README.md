## 📌 About the Project

This project focuses on **Exploratory Data Analysis (EDA)** of Google Play Store applications and reviews. It aims to understand app characteristics, identify patterns in ratings and installations, examine data quality, and discover meaningful insights through statistical analysis and visualisation.

Using Python and its data analysis libraries, the project transforms raw app data into meaningful information that helps understand trends in the mobile application ecosystem.

## 🎯 Project Objectives

- Understand the structure and characteristics of the dataset.
- Identify and handle missing values, duplicates and inconsistent data.
- Perform feature engineering and data transformation.
- Analyse app ratings, installations and prices.
- Explore statistical distributions and descriptive statistics.
- Apply sampling and the Central Limit Theorem.
- Examine relationships between numerical variables.
- Create visualisations to communicate analytical findings.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/your-username/Google-Play-Store-EDA.git
```

**2. Navigate to the project folder**

```bash
cd Google-Play-Store-EDA
```

**3. Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**4. Download the dataset**

Download the Google Play Store dataset from Kaggle and place the required CSV files inside the `Dataset` folder.

**5. Launch Jupyter Notebook**

```bash
jupyter notebook
```

Open the notebook and run the cells from beginning to end.
